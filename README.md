# Sistema de Cadastro de Alunos

Projeto desenvolvido em Python com o objetivo de praticar e aplicar conhecimentos de programação.

## 📚 Sobre o projeto

Sistema simples de cadastro e gerenciamento de alunos desenvolvido durante meus estudos de Python.

O projeto utiliza conceitos como:

* Variáveis e tipos de dados
* Estruturas condicionais
* Laços de repetição
* Listas e dicionários
* Funções
* Tratamento de erros
* Organização de código

## 🤖 Uso de Inteligência Artificial

A Inteligência Artificial foi utilizada como **ferramenta de apoio durante o desenvolvimento**, principalmente para tirar dúvidas, receber explicações sobre conceitos e auxiliar na resolução de problemas.

**O código não foi simplesmente copiado e colado.** As funcionalidades foram desenvolvidas por mim com base nos conhecimentos que estou estudando, utilizando a IA como suporte para aprendizado e orientação.

## 🎯 Objetivo

Praticar Python através do desenvolvimento de um projeto próprio e evoluí-lo gradualmente conforme avanço nos estudos.
